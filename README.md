# Netflix App

A movie-browsing app built with Expo, React Native, and TypeScript. Browse categories, scroll through movie posters, and open a movie to view its details. Movie data comes from the [OMDB API](https://www.omdbapi.com/).

## Features

- Vertically scrolling categories with horizontal movie lists.
- Paginated movie searches using RTK Query infinite queries.
- Movie details with a poster, rating, genres, plot, director, and cast.
- Light and dark themes that follow the device setting.
- Loading and error states, retrying details requests, and poster fallbacks.
- Safe-area layouts and typed navigation with React Navigation.

## Stack

- Expo SDK 57 and React Native 0.86.
- React 19 and TypeScript with strict checking.
- Redux Toolkit and RTK Query for fetching and caching data.
- React Navigation native stack.
- React Native Safe Area Context.

## Getting started

Install dependencies using the committed lockfile:

```sh
npm ci
```

### API configuration

Requests require an OMDB API key. Register for a key on the [OMDB website](https://www.omdbapi.com/apikey.aspx), then replace the `api_key` value in `src/constants/constants.ts` with your own key. The shared API configuration in `src/store/rootApi.ts` imports this constant and adds it to every request. The current implementation does not read an environment variable.

An internet connection is required to fetch movie data and remote posters.

### Run the app

Start the Expo development server:

```sh
npm start
```

Use Expo Go on a device, or a compatible simulator/emulator, to open the app.

To generate and run a local native build:

```sh
npm run ios
# or
npm run android
```

Local iOS builds require macOS and Xcode. Local Android builds require Android Studio and the Android SDK. Native projects are generated by Expo and are ignored by Git.

To start the web version:

```sh
npm run web
```

## Project structure

```text
src/
  constants/             # Movie category definitions
  navigation/            # Stack navigator and route types
  screens/               # Home and movie details screens
  features/
    movies/
      api/               # Query endpoints and response types
      components/        # Cards, category lists, overview, and credits
      types/             # Movie data models
  shared/
    components/          # Page wrapper, theme provider, loading, and errors
    hooks/               # Theme and typed navigation hooks
    styles/              # Theme colors, spacing, typography, and radii
    utils/               # Shared data helpers
  store/                 # Redux store and shared API configuration
```

Screens handle data fetching and page composition. Movie components receive presentation data through props, while shared components provide layout and theme behavior. RTK Query caches each category's movie pages and movie details by IMDb ID.

## Checks
